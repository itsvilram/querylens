# QueryLens web

Vue 3 (Composition API) + TypeScript + Vite frontend. See the [main README](../README.md) for how to run everything.

```sh
npm install
npm run dev            # http://localhost:5173 (calls to /api go to the API on :8000)
npm test               # unit tests (Vitest)
npm run lint && npm run format:check && npm run type-check
npm run build          # type-check + production build into dist/
```
